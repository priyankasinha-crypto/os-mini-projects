# Personal Task Manager

## 📌 Problem Statement

Users often need a simple way to monitor the applications and processes running on their computer and understand how system resources are being utilized.

## 💡 Proposed Solution

The Personal Task Manager is a desktop utility that displays running processes and their resource usage.

The application can provide information such as:

- Process ID
- Process Name
- CPU Usage
- Memory Usage
- Process Status

## 🧠 Operating System Concepts

- Process Management
- CPU Scheduling
- Multithreading
- Memory Management
- System Monitoring

## 🎯 Objectives

- Monitor running processes.
- Display CPU utilization.
- Display memory utilization.
- Identify resource-intensive processes.
- Provide a simple user-friendly interface.

## 🛠️ Technology

- Python
- Tkinter
- psutil

## ⭐ Proposed Features

### Basic Version

- Display running processes.
- Display CPU usage.
- Display memory usage.

### Intermediate Version

- Search processes.
- Refresh process information.
- Sort by CPU usage.
- Sort by memory usage.

### Advanced Version

- Process termination.
- Real-time graphs.
- Process categorization.
- Resource usage alerts.

## 📚 Learning Outcomes

After completing this project, students will understand:

- How operating systems manage processes.
- How processes consume CPU and memory.
- How system information can be accessed programmatically.
- How multithreading can improve application responsiveness.
